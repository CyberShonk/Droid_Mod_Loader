# Droid Mod Loader v0.5.5-beta

## Summary

This release improves archive metadata tracking and diagnostics used during
archive import.

## Changes

* Improved archive metadata tracking and summaries.
* Improved Nexus URL metadata parsing for imported archive records.
* Added archive metadata diagnostics that do not modify data.

## Notes

This release does not add full Nexus browsing, Nexus API downloads, collections,
or a download queue.

## Validation

* Unit tests pass.
* Release APK builds.
* Saved archive metadata can be inspected through the app's diagnostics.
